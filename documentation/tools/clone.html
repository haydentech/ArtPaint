The Clone tool - D

With this tool, you can copy parts of an image.

You can either set the Size of your stamp or opt to Use current brush with the currently configured tip in the Brushes window.

Pressure controls how firmly the stamp touches the canvas; the lighter the touch, the more transparent the stamp.

You start by right-clicking into the canvas to set the source area that gets cloned. It gets marked with crosshairs of the size of the stamp. Now you paint with the left mouse button, to clone the marked area.
While you draw, the source area follows the mouse pointer. When you lift the mouse button and start painting again, the source area snaps back to the initially set origin. With Relative to cursor, the origin snaps to the mouse pointer instead, in the same relative position of the originally set origin.

Include all layers or the clone action is limited to the current layer.

The quick key to choose the clone tool is D.
